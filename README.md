# 🍽️ FlavorGen AI — Gourmet Recipe Architect

> An AI-powered recipe generator that turns your pantry ingredients or dish cravings into professional, gourmet recipes — complete with food photography, nutrition charts, and a personal recipe collection.

---

## ✨ Features

- **Pantry Challenge Mode** — Add ingredients you already have, and the AI builds a creative recipe using only what's available
- **Direct Dish Mode** — Type any dish name (e.g. *Butter Chicken*, *Dal Makhani*) and get an authentic, step-by-step recipe
- **AI-Generated Food Photography** — Every recipe comes with a professionally styled food image generated by Gemini
- **Nutrition Chart** — Visual breakdown of calories, protein, carbs, and fat per recipe
- **Dietary Preferences** — Filter by Vegetarian, Vegan, or Jain; choose from Indian, Mediterranean, Asian, Mexican, or Italian cuisine
- **Recipe Collection** — Save your favourite recipes and browse them anytime from your personal collection
- **Skill Level Selector** — Recipes tailored to Beginner, Intermediate, or Expert chefs

| Layer | Technology |

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- A [Google Gemini API key](https://aistudio.google.com/app/apikey)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/your-username/flavorgen-ai.git
cd flavorgen-ai

# 2. Install dependencies
npm install

# 3. Add your Gemini API key
# Open .env.local and set:
GEMINI_API_KEY=your_api_key_here

# 4. Start the development server
npm run dev
```

The app will be running at `http://localhost:5173`

## 📖 How to Use

1. **Add Ingredients** — Type ingredients you have on hand and press `+` to add them to your pantry list
2. **Or Enter a Dish** — Type the name of a specific dish you want to cook in the "Direct Dish" field
3. **Set Preferences** — Choose your cuisine style and any dietary restrictions
4. **Click "Start Architecting"** — Gemini generates a full recipe with ingredients, step-by-step instructions, nutrition info, and a food photo
5. **Save It** — Hit "Save Recipe" to add it to your personal collection
